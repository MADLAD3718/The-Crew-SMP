# The Crew SMP
This is a repository for the addon content in The Crew SMP, a multiplayer server designed around implementing a new feature suggestion from each player who joins.
All information regarding implemented features and new content can be found on the [wiki](https://github.com/MADLAD3718/The-Crew-SMP/wiki).

Some notable additions include customizable sailboats with interactive upgrade slots, updated regeneration systems, teleportation waystones, and a new magic/spell scroll system.
